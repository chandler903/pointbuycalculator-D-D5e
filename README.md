## 🧠 What Is a Point Buy Calculator?

A **Point Buy Calculator** is a tool used in D&D 5e to assign ability scores using a fixed number of points.

You start with base stats and spend points to increase them based on a cost system.

✔ No randomness  
✔ Fair for all players  
✔ Strategic character building  

## ⚙️ How the Point Buy System Works

### 🔹 Starting Stats
All abilities begin at **8**:

- Strength  
- Dexterity  
- Constitution  
- Intelligence  
- Wisdom  
- Charisma  

### 🔹 Total Points
You get **27 points** to spend.

### 🔹 Score Limits
- Minimum: **8**  
- Maximum: **15 (before racial bonuses)**

## 🧮 Example Build

Let’s say you build a character like this:

- Strength → 15 (9 points)  
- Dexterity → 14 (7 points)  
- Constitution → 13 (5 points)  

Total used:

9 + 7 + 5 = 21 points

You still have **6 points left** for other stats.
